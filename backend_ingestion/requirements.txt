# ⚠️ setuptools 必须钉 <81：passlib 1.7.4 在 `passlib/pwd.py:16` 无条件 `import pkg_resources`，
# 而 **setuptools>=81 已移除 pkg_resources 模块**（官方原文：*"The pkg_resources package is
# slated for removal as early as 2025-11-30. Refrain from using this package or pin to
# Setuptools<81."*）。链式后果：`import fastapi_users` → `fastapi_users/password.py:3
# from passlib import pwd` → `passlib/pwd.py:16 import pkg_resources` →
# ModuleNotFoundError → uvicorn 起不来。
# 本机实测（Python 3.13.16 干净 venv）：setuptools 84.0.0 下上链必崩；80.9.0（<81）下
# `import pkg_resources` 可用（仅 DeprecationWarning），`import fastapi_users` 返回 12.1.3。
# 注意 python:3.11-slim 镜像虽自带 setuptools，但重建时会拉到最新版，故必须在此钉死。
# 长期正解是移除 passlib（升级 fastapi-users>=13 走 pwdlib），见 orders/20-dispatch.md T4。
setuptools<81
# ⚠️ bcrypt 必须钉在 4.x：passlib 1.7.4（fastapi-users 的密码哈希后端）会读取
# `bcrypt.__about__.__version__` 做后端探测，而 **bcrypt 5.0.0 删掉了 `__about__`**，
# 于是 passlib 回退到 `detect_wrap_bug()` 探针，在探针里用 72+ 字节口令调 hashpw，
# bcrypt 5.x 改为直接抛 ValueError → 注册/登录全部 500。
# 本机实测：bcrypt 5.0.0 下 POST /auth/register 返回 500（ValueError: password
# cannot be longer than 72 bytes）；降到 4.0.1 后 201。详见 PR 的「实测」章节。
bcrypt==4.0.1

# Support / 지원 / 支持

RobotMonitor is an international, open-source project. Help is available in **English, 한국어, 中文, 日本語**.

## Where to ask
- **Ideas, usage questions, and community discussion** → [GitHub Discussions](https://github.com/TopRemnantAcademy/robot-monitor/discussions). Start in the *Ideas* category, or say hello in the *Welcome* thread (#16).
- **Bug reports** → use the [Bug Report](https://github.com/TopRemnantAcademy/robot-monitor/issues/new?template=bug_report.yml) issue template.
- **Feature requests** → use the [Feature Request](https://github.com/TopRemnantAcademy/robot-monitor/issues/new?template=feature_request.yml) template, or post in Discussions first.
- **Security vulnerabilities** → see [SECURITY.md](./SECURITY.md). **Do not** open public issues for security problems.

## Before you ask
- Read the [README](./README.md) (and [README.ko.md](./README.ko.md) / [README.zh.md](./README.zh.md)).
- Check [open issues](https://github.com/TopRemnantAcademy/robot-monitor/issues) and Discussions for an existing answer.
- For local setup, follow [docs/developer-guide.md](./docs/developer-guide.md).

We aim to respond within a few business days. Contributions are welcome — see [CONTRIBUTING.md](./CONTRIBUTING.md).
